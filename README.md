# phone-task-playbook

安卓手机上「用 DSH 手机操控跑真实任务」的实战手册 + 经验库。

覆盖：学习通/超星作业与章节任务点、微信发消息与发文件、外卖/购物类 App 的下单链路、
坐标换算与可靠性避坑、任务复盘与写回协议。

## 文件

- `SKILL.md` —— 手册正文（§1 原则 / §2 坐标 / §5 坑 / §6 学习通 / §7 微信 / §9 复盘协议 / §10 经验库）
- `scripts/coords.py` —— 设备像素 ↔ 截图像素批量换算

## 说明

本仓库是**自动生成的脱敏版**：联系人姓名、课程名、宿主 App 包名等个人信息已替换为占位符
（`联系人A/B/C/D`、`课程A/B`、`<宿主App包名>`）。正文里的经验条目会持续追加。

每周由定时任务自动同步一次。发现错漏欢迎提 issue。
